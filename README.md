## Фабрика Протеста

Фабрика Протеста - это каталог готовых материалов для гражданского протеста и агитации против диктатуры Путина и партии «Единая Россия». 

Плакаты, листовки, стикеры, трафареты, файлы для печати, 3D-модели и рисунки для одежды. Выбираешь материал, скачиваешь и изготавливаешь своими руками, без типографий и сервисов-посредников. Или скачиваешь и распространяешь готовые материалы онлайн.

В этом репозитории GitHub находятся сами файлы протестных материалов. 

Полный каталог с описаниями на официальном сайте проекта: https://www.fabrika-protesta.org
